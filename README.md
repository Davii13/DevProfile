# 🚀 DevProfile – Portfólio Profissional

DevProfile é um website de portfólio profissional desenvolvido com foco em apresentar trajetória, habilidades, projetos e formas de contato de maneira moderna, responsiva e acessível.

O projeto foi desenvolvido como atividade prática de laboratório, contemplando front-end, back-end e hospedagem em nuvem.
